# dotfiles

Personal macOS dotfiles and bootstrap scripts.

The default setup is intentionally small:

- `Brewfile` is the package and application inventory.
- `setup-a-new-machine.sh` installs Xcode Command Line Tools, Homebrew, the
  Brewfile, and then links dotfiles.
- `symlink-setup.sh` links only the explicit files listed in the script.
- `docs/usage-audit.md` is generated by `scripts/audit-command-usage.py`.
- `docs/usage-decisions.md` records the human decisions behind the cleanup.

## Fresh Machine

Clone the repo, then run the bootstrap script:

```bash
git clone https://github.com/brianfryer/dotfiles.git ~/development/dotfiles
cd ~/development/dotfiles
./setup-a-new-machine.sh
```

Open a new shell after the script finishes so login and interactive shell files
are loaded from their symlinked locations.

## Package Inventory

Preview whether the current machine satisfies the Brewfile:

```bash
brew bundle check --file Brewfile
```

Install or update the Brewfile inventory:

```bash
brew bundle install --file Brewfile
```

Do not run the install command casually. It changes the local machine by
installing or updating formulae and applications.

## Linking Dotfiles

Link committed dotfiles into `$HOME`:

```bash
./symlink-setup.sh
```

Preview link operations without changing files:

```bash
./symlink-setup.sh --dry-run
```

The script prompts before replacing a path that already exists and is not
already the expected symlink.

## Usage Audit

Regenerate the usage report:

```bash
./scripts/audit-command-usage.py > docs/usage-audit.md
```

The audit reports command names only. It does not print raw shell-history lines
or command arguments.
